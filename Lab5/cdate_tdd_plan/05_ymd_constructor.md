# Название этапа
Реализовать конструктор из `day/month/year` с переводом в timestamp.

## Цель
После этапа `CDate(day, month, year)` создаёт валидную дату и корректный timestamp.

## Предусловие
Завершён `04_getters_from_timestamp.md`.

## Список задач
1. Написать тесты для конструктора `CDate(day, month, year)` на валидных датах.
2. Реализовать `daysBeforeYear(year)`.
3. Реализовать `daysBeforeMonth(year, month)`.
4. Реализовать формулу `timestamp=daysBeforeYear+daysBeforeMonth+(day-1)`.
5. Проверить round-trip через геттеры.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `01.01.1970` -> `timestamp=0`.
2. `02.01.1970` -> `timestamp=1`.
3. `01.03.2024` -> корректная дата через геттеры.
4. `31.12.9999` -> корректная дата через геттеры.
5. Таблица валидных дат -> стабильный round-trip.

## Критерий завершённости
Конструктор из компонентов корректно переводит дату во внутренний timestamp.

## Типичные ошибки
1. Забыть `day-1`.
2. Перепутать номер месяца.
3. Неверно посчитать дни до года.
