# Название этапа
Реализовать операторы сравнения `==` и `!=`.

## Цель
После этапа можно корректно проверять равенство и неравенство дат.

## Предусловие
Завершён `14_compound_assignment.md`.

## Список задач
1. Написать тесты для `==` и `!=`.
2. Зафиксировать политику сравнения invalid с invalid и invalid с valid.
3. Реализовать `==` через сравнение валидности и `timestamp`.
4. Реализовать `!=` как логическое отрицание `==`.
5. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. Две одинаковые валидные даты -> `== true`, `!= false`.
2. Две разные валидные даты -> `== false`, `!= true`.
3. invalid и valid -> по выбранной политике.
4. invalid и invalid -> по выбранной политике.

## Критерий завершённости
`==` и `!=` дают согласованные результаты для всех комбинаций состояний.

## Типичные ошибки
1. Сделать `!=` с отдельной логикой и получить противоречия.
2. Не учесть valid/invalid.
3. Сравнивать только timestamp без валидности.
