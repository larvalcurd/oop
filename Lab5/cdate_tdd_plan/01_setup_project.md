# Название этапа
Настроить проект и тестовую инфраструктуру для TDD разработки CDate.

## Цель
После этапа проект собирается, тесты запускаются, каркас CDate существует.

## Предусловие
Завершён `00_analysis.md`.

## Список задач
1. Создать `CDate.h` и `CDate.cpp`.
2. Создать `tests/CDateTests.cpp`.
3. Подключить тестовый фреймворк к сборке.
4. Добавить цель запуска тестов.
5. Объявить `Month`, `WeekDay`, все сигнатуры из задания.
6. Добавить минимальные заглушки, чтобы всё компилировалось.
7. Запустить сборку.
8. Запустить тесты.

## Тесты, которые нужно написать ДО реализации
1. Тестовый раннер стартует.
2. `#include "CDate.h"` в тесте компилируется.
3. Создание `CDate date;` компилируется и линкуется.

## Критерий завершённости
Сборка и тестовый запуск работают, API класса объявлен полностью.

## Типичные ошибки
1. Не добавить `CDate.cpp` в цель тестов.
2. Нарушить сигнатуры из задания.
3. Развести разные enum в тестах и коде.
