# Название этапа
Реализовать `GetDay`, `GetMonth`, `GetYear` через конвертацию timestamp в дату.

## Цель
После этапа геттеры возвращают корректные компоненты для валидной даты.

## Предусловие
Завершён `03_timestamp_constructor.md`.

## Список задач
1. Написать тесты для `GetDay/GetMonth/GetYear`.
2. Реализовать `isLeapYear(year)`.
3. Реализовать `daysInMonth(year, month)`.
4. Реализовать конвертацию `timestamp -> year` без циклов по годам.
5. Реализовать поиск `month/day` внутри года (разрешён цикл по месяцам).
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `timestamp=0` -> `01.01.1970`.
2. `timestamp=31` -> `01.02.1970`.
3. timestamp даты `29.02.2024` -> корректные day/month/year.
4. timestamp даты `31.12.9999` -> корректные day/month/year.
5. Несколько случайных timestamp -> согласованные геттеры.

## Критерий завершённости
Геттеры стабильно восстанавливают дату из timestamp на обычных и граничных кейсах.

## Типичные ошибки
1. Ошибка `off-by-one` в дне.
2. Ошибка февраля в високосный год.
3. Цикл по годам вместо формулы.
