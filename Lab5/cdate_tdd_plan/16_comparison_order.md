# Название этапа
Реализовать операторы порядка `<`, `>`, `<=`, `>=`.

## Цель
После этапа даты корректно упорядочиваются по времени.

## Предусловие
Завершён `15_comparison_eq_ne.md`.

## Список задач
1. Написать тесты на строгие и нестрогие сравнения.
2. Зафиксировать поведение сравнений с invalid.
3. Реализовать базовый оператор `<`.
4. Реализовать `>` через `<`.
5. Реализовать `<=` и `>=` через `<` и `==`.
6. Проверить логические инварианты сравнений.
7. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `01.01.2010` и `02.01.2010` -> `< true`, `> false`, `<= true`, `>= false`.
2. Две одинаковые даты -> `< false`, `> false`, `<= true`, `>= true`.
3. Три даты `a < b < c` -> транзитивность.
4. Комбинации с invalid -> заранее определённая политика.

## Критерий завершённости
Операторы порядка реализованы согласованно и проходят матрицу сравнений.

## Типичные ошибки
1. Получить конфликт между `<=` и `<`.
2. Не определить поведение при invalid.
3. Сравнивать только день и месяц.
