# Сводный чеклист тестов CDate

## Конструкторы
- `CDate()` -> `01.01.1970`, valid.
- `CDate(0)` -> `01.01.1970`.
- `CDate(1)` -> `02.01.1970`.
- `CDate(maxTimestamp)` -> `31.12.9999`.
- `CDate(maxTimestamp+1)` -> invalid.
- `CDate(day, month, year)` на валидных датах.

## Геттеры
- `GetDay/GetMonth/GetYear` на начале эпохи.
- `GetDay/GetMonth/GetYear` на конце диапазона.
- `GetDay/GetMonth/GetYear` на случайных датах.
- Round-trip `ymd -> timestamp -> ymd`.

## Валидность
- `IsValid` на валидных датах.
- `31.04.xxxx` -> invalid.
- `29.02` невисокосного года -> invalid.
- Год `<1970` и `>9999` -> invalid.
- Месяц `0` и `13` -> invalid.

## День недели
- `01.01.1970` -> `THURSDAY`.
- `04.01.1970` -> `SUNDAY`.
- `01.01.2000` -> `SATURDAY`.
- `29.02.2024` -> `THURSDAY`.

## Арифметика
- `date + n`: `28.02.2010 + 3 = 03.03.2010`.
- `n + date`: эквивалентно `date + n`.
- `date - n`: `01.01.2010 - 2 = 30.12.2009`.
- `date1 - date2`: положительный, ноль, отрицательный результат.
- `+=` и `-=` эквивалентны бинарным операциям.
- Префиксные `++`, `--`.
- Постфиксные `++`, `--` с возвратом старого значения.

## Сравнения
- `==` и `!=` для одинаковых дат.
- `==` и `!=` для разных дат.
- `<` и `>` для соседних дат.
- `<=` и `>=` для равных дат.
- Транзитивность порядка.
- Комбинации с invalid по выбранной политике.

## Ввод/вывод
- `<<` для валидной даты: `ДД.ММ.ГГГГ`.
- `<<` для invalid: `INVALID`.
- `>>` для строки `ДД.ММ.ГГГГ`.
- `>>` для строки `INVALID`.
- `>>` на неверных разделителях.
- `>>` на мусорной строке: `failbit`.

## Граничные случаи
- `31.12.9999 ++` -> invalid.
- `01.01.1970 --` -> invalid.
- `+/-` с выходом за верхнюю границу -> invalid.
- `+/-` с выходом за нижнюю границу -> invalid.

## Високосные годы
- 2024 високосный.
- 2023 невисокосный.
- 2000 високосный.
- 1900 невисокосный (правило формулы).
- Переход `28.02 -> 29.02 -> 01.03` в високосный год.

## Невалидные даты
- invalid после `++` остаётся invalid.
- invalid после `--` остаётся invalid.
- invalid после `+=` и `-=` остаётся invalid.
- invalid после `+` и `-` остаётся invalid.
- invalid печатается как `INVALID`.
- Сравнения invalid с valid и invalid с invalid покрыты тестами.
