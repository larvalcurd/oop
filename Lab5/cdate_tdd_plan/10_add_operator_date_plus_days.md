# Название этапа
Реализовать оператор `date + days`.

## Цель
После этапа сложение возвращает новую дату со сдвигом на заданное число дней.

## Предусловие
Завершён `09_postfix_increment_decrement.md`.

## Список задач
1. Написать тесты для `date + days`.
2. Реализовать вычисление нового timestamp без изменения исходного объекта.
3. Реализовать обработку отрицательных `days`.
4. Реализовать перевод результата в invalid при выходе за диапазон.
5. Реализовать поведение для invalid-операнда.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `28.02.2010 + 3` -> `03.03.2010`.
2. `01.03.2024 + (-1)` -> `29.02.2024`.
3. `31.12.9999 + 1` -> invalid.
4. `01.01.1970 + (-1)` -> invalid.
5. `invalid + 10` -> invalid.

## Критерий завершённости
`date + days` корректно работает как немутирующая операция на всём диапазоне.

## Типичные ошибки
1. Изменить исходный объект.
2. Ошибиться со знаком.
3. Не обработать выход за границы.
