# Название этапа
Реализовать свободный оператор `days + date`.

## Цель
После этапа обе формы сложения дают идентичный результат.

## Предусловие
Завершён `10_add_operator_date_plus_days.md`.

## Список задач
1. Написать тесты на симметрию `days + date` и `date + days`.
2. Объявить свободный `operator+(int days, const CDate& date)`.
3. Реализовать делегирование в `date + days`.
4. Проверить поведение на invalid и границах.
5. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `3 + 28.02.2010` -> `03.03.2010`.
2. `-1 + 01.03.2024` -> `29.02.2024`.
3. `days + invalid` -> invalid.
4. `x + date` равно `date + x` для набора `x`.

## Критерий завершённости
`days + date` реализован и не расходится по логике с `date + days`.

## Типичные ошибки
1. Реализовать отдельную логику с расхождениями.
2. Потерять `const`.
3. Выбрать неподходящий тип параметра дней.
