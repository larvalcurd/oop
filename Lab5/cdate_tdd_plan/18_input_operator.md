# Название этапа
Реализовать оператор ввода `>>` для формата `ДД.ММ.ГГГГ` и литерала `INVALID`.

## Цель
После этапа объект корректно читает валидную дату, invalid и предсказуемо обрабатывает ошибочный ввод.

## Предусловие
Завершён `17_output_operator.md`.

## Список задач
1. Написать тесты на валидные и невалидные входные строки.
2. Реализовать разбор шаблона `ДД.ММ.ГГГГ`.
3. Реализовать распознавание точного литерала `INVALID`.
4. Реализовать валидацию разобранных компонентов.
5. Реализовать установку `failbit` при неразбираемом вводе.
6. Зафиксировать, меняется ли объект при ошибке ввода.
7. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `01.01.1970` -> валидная дата.
2. `INVALID` -> invalid-состояние.
3. `31.04.2024` -> invalid.
4. `1.1.1970` -> поведение согласно контракту формата.
5. `01-01-1970` -> `failbit`.
6. `abc` -> `failbit` и оговорённое состояние объекта.

## Критерий завершённости
Оператор `>>` стабильно принимает корректные строки и корректно обрабатывает ошибки.

## Типичные ошибки
1. Принимать частично корректные строки.
2. Не выставлять `failbit`.
3. Неопределённо менять объект при ошибке.
