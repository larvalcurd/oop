# Название этапа
Реализовать `GetWeekDay` по формуле без циклов.

## Цель
После этапа день недели вычисляется корректно для валидных дат.

## Предусловие
Завершён `06_validity_and_invalid_strategy.md`.

## Список задач
1. Написать тесты на контрольные даты weekday.
2. Зафиксировать опорную дату: `01.01.1970 = THURSDAY`.
3. Реализовать формулу `weekday=(4+timestamp)%7`.
4. Преобразовать индекс в `WeekDay`.
5. Зафиксировать поведение на invalid.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `01.01.1970` -> `THURSDAY`.
2. `04.01.1970` -> `SUNDAY`.
3. `29.02.2024` -> `THURSDAY`.
4. `01.01.2000` -> `SATURDAY`.
5. invalid -> выбранное и зафиксированное поведение.

## Критерий завершённости
`GetWeekDay` работает без циклов и проходит контрольные кейсы.

## Типичные ошибки
1. Ошибиться в смещении относительно четверга.
2. Перепутать порядок enum дней недели.
3. Не определить поведение invalid.
