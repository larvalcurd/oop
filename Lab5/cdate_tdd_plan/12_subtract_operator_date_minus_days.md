# Название этапа
Реализовать оператор `date - days`.

## Цель
После этапа вычитание дней возвращает новую корректную дату.

## Предусловие
Завершён `11_add_operator_days_plus_date.md`.

## Список задач
1. Написать тесты для `date - days`.
2. Реализовать оператор через `date + (-days)`.
3. Проверить переходы через месяц/год.
4. Проверить обработку выхода за диапазон.
5. Проверить поведение для invalid.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `01.01.2010 - 2` -> `30.12.2009`.
2. `01.03.2024 - 1` -> `29.02.2024`.
3. `01.01.1970 - 1` -> invalid.
4. `invalid - 10` -> invalid.

## Критерий завершённости
`date - days` согласован со сложением и корректен на границах.

## Типичные ошибки
1. Перепутать знак.
2. Дублировать код и получить несогласованность.
3. Менять исходный объект.
