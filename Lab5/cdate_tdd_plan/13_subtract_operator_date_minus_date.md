# Название этапа
Реализовать оператор разности двух дат `date1 - date2` со знаком.

## Цель
После этапа разность двух валидных дат возвращается как signed-количество дней.

## Предусловие
Завершён `12_subtract_operator_date_minus_days.md`.

## Список задач
1. Написать тесты на положительную, нулевую и отрицательную разность.
2. Выбрать signed-тип результата и зафиксировать его в интерфейсе.
3. Реализовать вычисление как `timestamp1 - timestamp2`.
4. Зафиксировать поведение на invalid-операндах в тестах.
5. Реализовать выбранную политику поведения на invalid.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `01.01.2010 - 30.12.2009` -> `3`.
2. `01.01.2010 - 03.01.2010` -> `-2`.
3. `date - sameDate` -> `0`.
4. `valid - invalid` и `invalid - valid` -> заранее зафиксированная политика.

## Критерий завершённости
Разность дат вычисляется со знаком и проходит примеры из задания.

## Типичные ошибки
1. Взять модуль разности и потерять знак.
2. Использовать unsigned-тип результата.
3. Не определить поведение на invalid.
