# Название этапа
Реализовать конструктор по умолчанию для даты 01.01.1970.

## Цель
После этапа `CDate()` создаёт валидную дату начала диапазона.

## Предусловие
Завершён `01_setup_project.md`.

## Список задач
1. Написать тесты для `CDate()`.
2. Добавить внутреннее поле `timestamp`.
3. Добавить внутренний флаг `valid`.
4. Установить `timestamp=0` и `valid=true` в конструкторе по умолчанию.
5. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `CDate()` даёт `IsValid()==true`.
2. `CDate()` представляет 01.01.1970.
3. Два объекта `CDate()` эквивалентны.

## Критерий завершённости
Конструктор по умолчанию стабильно создаёт валидную эпоху.

## Типичные ошибки
1. Сместить эпоху на один день.
2. Не инициализировать `valid`.
3. Привязать поведение к системной дате.
