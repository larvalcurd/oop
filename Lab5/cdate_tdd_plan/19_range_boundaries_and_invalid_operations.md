# Название этапа
Покрыть все операции единым поведением на границах диапазона и при invalid.

## Цель
После этапа любой выход за диапазон переводит результат в invalid, а операции над invalid не меняют объект.

## Предусловие
Завершён `18_input_operator.md`.

## Список задач
1. Написать интеграционные тесты на границы диапазона для всех мутационных операторов.
2. Написать интеграционные тесты на неизменность invalid для всех операторов.
3. Вынести общую функцию проверки диапазона после мутации.
4. Применить общую проверку во всех точках изменения состояния.
5. Вынести общий ранний выход для invalid.
6. Запустить полный набор тестов.

## Тесты, которые нужно написать ДО реализации
1. `31.12.9999` с `++`, `+=1`, `+1` -> invalid.
2. `01.01.1970` с `--`, `-=1`, `-1` -> invalid.
3. invalid с `++`, `--`, `+=`, `-=`, `+`, `-` -> без изменений.
4. invalid в сравнениях -> строго по выбранной политике.
5. invalid в `<<` -> `INVALID`.

## Критерий завершённости
Поведение на границах и invalid единообразно для всего API.

## Типичные ошибки
1. Пропустить один оператор и получить разное поведение.
2. Сделать разную политику invalid в разных блоках.
3. Проверять границы не в той точке.
