# Название этапа
Реализовать оператор вывода `<<` в формате `ДД.ММ.ГГГГ` или `INVALID`.

## Цель
После этапа дата корректно печатается в поток в требуемом формате.

## Предусловие
Завершён `16_comparison_order.md`.

## Список задач
1. Написать тесты на формат вывода.
2. Реализовать вывод `INVALID` для невалидной даты.
3. Реализовать вывод дня и месяца с ведущими нулями.
4. Реализовать вывод года четырьмя цифрами.
5. Убедиться, что формат не содержит лишних пробелов.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `01.01.1970` -> `01.01.1970`.
2. `09.02.2024` -> `09.02.2024`.
3. invalid -> `INVALID`.
4. Несколько дат подряд в поток -> точный формат без артефактов.

## Критерий завершённости
Оператор `<<` строго соответствует формату задания.

## Типичные ошибки
1. Потерять ведущие нули.
2. Вывести `invalid` в другом регистре.
3. Сломать состояние форматирования потока.
