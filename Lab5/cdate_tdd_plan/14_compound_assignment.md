# Название этапа
Реализовать операторы `+=` и `-=`.

## Цель
После этапа мутационные арифметические операторы изменяют объект и согласованы с `+` и `-`.

## Предусловие
Завершён `13_subtract_operator_date_minus_date.md`.

## Список задач
1. Написать тесты для `+=` и `-=`.
2. Реализовать `+=` через `*this = *this + days`.
3. Реализовать `-=` через `*this = *this - days`.
4. Проверить возврат ссылки на текущий объект.
5. Проверить no-op поведение для invalid.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `28.02.2010 += 3` -> `03.03.2010`.
2. `01.01.2010 -= 2` -> `30.12.2009`.
3. `31.12.9999 += 1` -> invalid.
4. `invalid += 10` и `invalid -= 10` -> invalid без изменений.
5. Выражение `(date += 1)` возвращает ссылку на `date`.

## Критерий завершённости
`+=` и `-=` корректно мутируют объект и не расходятся с бинарными операторами.

## Типичные ошибки
1. Вернуть копию вместо ссылки.
2. Дублировать вычисления и получить другую семантику.
3. Потерять обработку invalid.
