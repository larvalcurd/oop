# Название этапа
Реализовать постфиксные операторы `++` и `--`.

## Цель
После этапа постфиксные операторы возвращают старое значение и корректно меняют текущий объект.

## Предусловие
Завершён `08_prefix_increment_decrement.md`.

## Список задач
1. Написать тесты для `date++` и `date--`.
2. Реализовать создание копии текущего состояния.
3. Вызвать префиксный оператор для изменения объекта.
4. Вернуть сохранённую копию.
5. Проверить поведение на границах и invalid.
6. Запустить тесты этапа.

## Тесты, которые нужно написать ДО реализации
1. `old=date++` для `15.05.2024` -> `old=15.05.2024`, `date=16.05.2024`.
2. `old=date--` для `01.03.2024` -> `old=01.03.2024`, `date=29.02.2024`.
3. `old=31.12.9999++` -> `old` валиден, новый `date` invalid.
4. `old=invalid++` -> `old` invalid и `date` invalid.

## Критерий завершённости
Постфиксные операторы соответствуют стандартной семантике C++.

## Типичные ошибки
1. Вернуть уже изменённый объект.
2. Дублировать логику вместо переиспользования префикса.
3. Неверно обработать переход в invalid.
