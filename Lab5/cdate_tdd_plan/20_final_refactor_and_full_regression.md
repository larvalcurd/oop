# Название этапа
Провести финальный рефакторинг и полный регрессионный прогон тестов.

## Цель
После этапа код остаётся функционально неизменным, но становится чище и устойчивее.

## Предусловие
Завершён `19_range_boundaries_and_invalid_operations.md`.

## Список задач
1. Написать регрессионные тесты для ранее найденных сложных кейсов.
2. Вынести повторяющиеся вычисления в приватные утилиты.
3. Упростить операторы через переиспользование базовых операций.
4. Удалить дублирующий и мёртвый код.
5. Проверить отсутствие циклов по годам в конвертациях и weekday.
6. Запустить полный набор тестов проекта.
7. Зафиксировать, что поведение после рефакторинга не изменилось.

## Тесты, которые нужно написать ДО реализации
1. Интеграционная цепочка: конструктор -> арифметика -> сравнение -> вывод.
2. Переходы вокруг 28/29 февраля в високосные и невисокосные годы.
3. Полный набор граничных кейсов диапазона.
4. Round-trip `date -> string -> date`.

## Критерий завершённости
Все тесты зелёные, код читаемый, каждый пункт задания покрыт.

## Типичные ошибки
1. Изменить поведение во время рефакторинга.
2. Потерять редкий граничный кейс.
3. Проверить не весь тестовый набор.
